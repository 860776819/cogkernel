# 人工预置机制审计（M0 = Baseline A）

> 2026-09-13。动机：M0 的「离线增益/鲁棒性」结论建立在大量程序员预置机制之上。
> 本文档逐项列出 Worm-0 大脑里**所有由设计者规定的机制**，并分类：
> 【基建】实验基础设施，删掉就没有实验可言，不构成对系统的认知主张；
> 【脚手架】可移除的搭建辅助，移除需配套调整但不预支认知结论；
> 【偷渡】"为了让它像会想而写的答案"——它替系统决定了一个本该涌现的东西。偷渡中再标注【承重】
> （M0 的核心结论依赖它，删除后结论必须重审）或【轻】。
>
> 范围：`src/` 下进入大脑的机制。`src/experiment.py` 的协议/指标/判据属于实验者侧【基建】，
> 不计入系统的认知债，但 §4 列出协议层对结论的隐含限制。

---

## 1. 偷渡清单（程序员替它想的答案）

### ★P1 晕厥→烧知识：生存与认知的兑换率是手工定的【偷渡·承重】
- 位置：`agent.tick_wake()` 晕厥分支：`memory.prune(0.10)`、`wm.forget(0.08)`、`dc.forget(0.08)`
- 替它决定了：**身体灾难=认知损失**。这是 M0 里"趋利避害能无标签涌现"的唯一因果通路：
  ΔC 预测器之所以学得到"低能量→坏事"，全靠这条人工桥。
- 删除代价：可能失去全部生存行为（见 M0M3 ablation）；也可能不失去——低能量→感官噪声→
  预测误差升→C 降，这条**物理侧弱通路**仍然存在。哪条通路承重，正是 M0M3 要测的。
- 审计备注：真实饥饿不选择性删记忆。这不是物理，是以物理语法书写的设计决定。

### ★P2 认知资本 C 被任命为行动的统一目标【偷渡·承重】
- 位置：`agent.policy()`/`rollout_scores()`：行动评分 = Σγ^k·dĈ(想象轨迹)；`dc` 网络输入输出与 `DC_DELAY=150` 信用窗口
- 替它决定了：** utilitarian 原则本身**——"行动=最大化想象中的认知收益"。
  M0 虫的每一次转向都在执行程序员安装的这套目标函数。它没有"选择"过 C 值得最大化。
- 删除代价：M0 的全部觅食/避害行为预期崩塌（M0M2 测之）。若不崩，说明 h 动力学+历史痕迹
  自带行为结构——那将比 M0 任何 PASS 都重要。
- 审计备注：C 的**测量**（探针集技能）是【基建】；C 的**任命**是【偷渡】。二者必须分开看。

### ★P3 自发回忆是定时任务【偷渡·承重】
- 位置：`agent.tick_wake()`：`tick % 10 == 0 and pulse_env < 0.3` 触发检索，阈值 0.90，
  脉冲内容 = 记忆条目的感觉段，经 `kernel.Wm` 注入 h
- 替它决定了：**什么时候回忆**（每 10 拍询问一次）和**回忆以什么形式进入意识**（注入格式）。
  "走神/浮上来的记忆"在 M0 里是一个 cron job。
- 删除代价：失去记忆→h 的全部上行通道，idle 脉冲仍在（同属定时）。核心问题"内部动力学
  能否自发路过一段记忆"在 M0 里**从未被测过**——我们只测了"被定时器踹一下时 h 会不会偏"。
  S4 的 PASS 因此必须降级解读：它证明注入通道工作正常，不证明自发回忆存在。

### ★P4 经验分区 + 学习进度是手工造的【偷渡·承重】
- 位置：`brain.ClusterTracker`：k=6 在线 k-means、质心 lr=0.05、`LP := err_slow(α=0.008) − err_fast(α=0.15)`、
  `min_n=8`、recency EMA；`agent._start_block()` 的特征 `[1, z(err), z(lp), z(dread), z(recency)]`
- 替它决定了：**经验以什么粒度被当作"一个地方"**，以及**"探究欲"的定义**
  （=我们选的误差斜率公式）。探究欲在 M0 里不是涌现的，是说明书。
- 删除代价：回放分配退化为均匀（≈已有的 uniform 臂）；"学会挑什么复习"这个问题失去载体。
- 审计备注：LP 公式与 Oudeyer 的 IAC 同构，有文献血统，但血统不豁免偷渡——
  它仍是我们规定"什么值得关注"，不是它发现的。

### ★P5 idle 期的内部工作是一张课表【偷渡·承重】
- 位置：`agent.tick_idle()`：`IDLE_BLOCK=50`；块首脉冲；`block_t ∈ {12,24,36,48}` 各一次 batch-32 重放训练；
  `_end_block()` 奖励公式 `(err_before−err_after)/(err_before+1e-6)` 喂 bandit
- 替它决定了：**何时内部工作、工作多久、复习以什么算子执行（聚类小批量SGD）、
  什么叫"这次复习划算"**。"内部重放"的整个语法是课表+算子包。
- 删除代价：P3 之外的第二大偷渡。E0 的"离线增益"结论依赖它——结论必须改写为
  "**被安排的**内部重放有增益"，与"自发内部工作有增益"是两个命题。

### P6 行动语法与探索策略是安装的【偷渡·轻】
- 位置：`agent.policy()`：`IM_EVERY=3` 决策节拍；手工候选集 `[0,0],[0,0.7],[±0.6,0.6]`+噪声扰动；
  ε 按相位手工排程（W1: 1.0→0.15，W3: 0.25，其余 0.15）；`memory.count<150` 时纯随机
- 替它决定了：动作词表（什么是"一个动作"）、探索率如何退火。
- 删除代价：连同 P2 一起删（M0M2）。

### P7 忧惧流入好奇心的桥【偷渡·轻】
- 位置：`brain.ClusterTracker.dread`（ΔC 实测标签的 EMA）进入 bandit 特征
- 替它决定了：恐惧是关切竞争里的一个出价者——这是 Dörner 式的直觉，
  但"恐惧以一个标量 EMA 参与_softmax"完全是设计。

### P8 记忆检索阈值【偷渡·轻】
- 位置：`memory.retrieve(thresh=0.90)`；键=编码时刻的 h，余弦相似度
- 替它决定了：多像算"想起"。三轮迭代里它在 0.62→0.80→0.90 之间被我们手动拧过——
  这个旋钮的存在本身就是证据：回忆的判定权在程序员手里。

## 2. 脚手架（可拆，但不预支认知结论）

- **醒/睡学习预算不对称**：`tick % 4` batch-6 醒时训练 vs idle 批量重放——
  "整合发生在低活动期"是我们的设计假设（有睡眠文献直觉），不是它的发现。
- **遗忘的实现形式**：`nets.forget(lam)` 权重线性混向初值——"知识怎么被烧"的语法是设计的。
- **身体能力的具体耦合形式**：能量/完整度→推力与感官噪声的乘性耦合（`world.capability()`、`_noise_scale()`）、
  食物可耗尽+再生参数（0.02/0.0003）。原方案声明"只规定物理后果"，这些属于声明范围，
  但耦合的**具体函数形式**是我们挑的，它们预先决定了身体状态与认知的带宽分配。

## 3. 基建（公理层，删掉则范式溶解，不算认知债）

- 恒定 tick + 32 维固定随机 kernel（`kernel.py`）——"时间恒在流动"是公理不是功能；
- 情景记忆的存储（每拍写、ring 3000、键=h）——历史痕迹；
- 世界物理与接触效应的存在本身（`world.py`）；
- 实验者侧：E0 协议、三臂、全部指标与判据、`tools/`。

## 4. 协议层对结论的隐含限制（不是系统的债，是解读的债）

1. **idle 是实验者排的**。虫从未"选择休息/做梦"——无输入期是外部强加的窗。
   M0 的全部"离线增益"都发生在我们指定的窗里。自发进入低活动态是尚未触及的现象。
2. **"内部事件"的检测窗也是我们定的**（S4 的脉冲期间对比）。P3 的 cron 决定了事件时刻，
   我们只是测量它——按定义不可能出现"非预定的内部事件"。
3. 对照臂只隔离了"内部工作 vs 无内部工作"，未隔离"谁决定做这个工作"。

## 5. 总账

M0 大脑里，程序员预置的**承重偷渡共 5 处**（P1 晕厥桥、P2 C 任命、P3 回忆课表、P4 分区与探究欲、
P5 idle 课表），轻偷渡 3 处。因此 M0 的正确表述是（对 FINDINGS 的降级修正）：

> 一个**被安装了价值目标、回忆课表、复习课表与探究欲定义**的持续系统，在被安排的无输入期内
> 执行**被安排的**内部工作，能产生功能增益；且该增益部分经由**人工设计的**生存-认知兑换率
> 转化为生存行为。

"代码开始自己想了"在 M0 中：**未证明，也未被测试。**

下一阶段问题（M0-minus 的靶心）：在没有 P2/P3/P5 的情况下，内部动力学本身能否产生
一次**非预定、可溯源、对未来有因果作用**的内部事件。
