# 认知内核（Worm-0）研究方案 v0

> 2026-09-13 初稿。本文档是手机端讨论的锚点：每一条机制都对应一个可测量的问题，每一条判据都可证伪。
> 协作方式：手机端自由发散推敲 → 电脑端落成方案/源码调查/原型/实验，实时修改方向。

---

## 1. 研究什么，不研究什么

**研究**：代码如何产生"想"。即：一个持续运行的认知内核，其内部状态在自己的动力学驱动下不断演化——外界输入只是对它的**扰动**，不是**启动信号**。

**不做**：数字分身、人格 Prompt、AI 伴侣、Agent 框架复刻、"先搭情绪系统"的路线。

**对现有 LLM 的定位**：LLM 是事件驱动的纯函数（有输入才运行一次，无持续状态项）。它以后可以作为**器官**接入（语言、抽象推理），但不是核心。核心必须是动力系统：

```
LLM:        output = f(input)            —— 时间不流动，被踹才运行
认知内核:    h(t+1) = F(h(t), s(t), ...)  —— 时间恒在生产，有没有输入都流
```

"想"的操作化定义（本文档全文围绕它）：**在没有新外界信息的情况下，内部动力学的演化仍然产生功能上新的认知产物**——新的预测、新的行为倾向、新的计算策略。"功能上新"必须是可测量的，见 §2。

---

## 2. 核心问题与可证伪判据

### Q1（离线心智）：外界冻结时，内部演化是否产生新的东西？

拆成三个可测子问题：

- **Q1a 结构性**：无输入阶段 h 的演化是结构化的（由记忆再激活/世界模型驱动），不是噪声漂移。
- **Q1b 增益性（最关键）**：无输入阶段，系统只消化**自己已有的经历**（信息守恒：外界进入大脑的比特数≈0），醒来后对真实世界的预测误差下降、行为改善。对照臂（同样的时间，只有噪声漂移、无内部工作）必须无改善。
- **Q1c 信息审计**：证明增益不可能来自新信息——记录无输入阶段感官流的熵（应≈0）与同时发生的内部认知增益。

### Q2（学会怎么想）：系统能否学到认知策略？

不只是学世界（世界模型变准），而是**学怎么计算**：何时回忆、回忆哪个、何时在内部模拟、信任模型还是信任记忆。第一版操作化为：**回放分配策略的习得**——系统自己学出"内部复习应该优先复习哪类经历"，用更少的内部算力换更多的预测改善，并检验该策略是否迁移。

### 判据表（E0 实验预注册，跑之前写下，跑完对答案）

| # | 判据 | 通过条件 |
|---|------|----------|
| S1 | 离线增益 | 满配臂：W2 相对 W1 末期的真实预测误差下降显著大于对照臂（≥5 个百分点差距，且自身下降≥8%） |
| S1' | 选择有值 | 满配臂 > 均匀回放臂（同等内部算力），差距≥3 个百分点 → "挑什么复习"本身有价值 |
| S2 | 行为变化 | W2 阶段晕厥次数相对 W1 下降，满配臂降幅 > 对照臂 → 预测改善传导到了行为 |
| S3 | 策略迁移 | 世界突变后（W3），满配臂的恢复速度相对其 W1 的加快幅度 > 对照臂 → 学到的是"怎么应对"而不只是"地图" |
| S4 | 结构性（弱判据） | 无输入期记忆再激活脉冲使 h 向被再激活记忆偏移（余弦相似度上升），即 idle 期 h 的活动可溯源到内部事件 |

任何一条不通过都是有效结果（说明该机制假设错了），如实记录到 FINDINGS。

## 3. 设计公理（红线，代码里可审计）

1. **持续运行是公理不是功能**：tick 恒定存在，h 每拍必更新；感知只是 F 的一个输入项。
2. **无标签价值**：不给系统任何"好坏/食物/危险"的标签或奖励函数。只规定**物理后果**（能量衰减、接触效应、身体状态调制能力、晕厥/麻痹事件）。"什么是好的"必须从经历里长出来。
   - 审计方法：搜索代码中所有进入大脑的训练信号——只能是自监督预测误差、内部学习进度、内部测得的认知资本变化。禁止出现 reward(energy) 之类。
3. **并行竞争**：多个内部关切（concern）同时演化、争夺有限的广播资源。思考不是串行流水线，也不是开关。
4. **探究欲 = 学习进度，不是新鲜感**：驱动力是"这里存在正在被学会/可能被学会的结构"（误差在下降的地方），不是"我没见过这个"。看到未知就扑上去是变态，不是好奇心。
5. **想象数据不直接入训练**（v0 保守决定）：内部模拟只用于行动评分；训练只吃过去真实经历的重放。理由：在错误模型上训练会自我中毒。生成式"做梦"（想象数据经置信度加权进入训练、回到真实时延期验证）推迟到 M1+。

**唯一的公理化内在目标**：认知资本 C(t) 的增长——世界模型在一组滚动探针（过去真实转移）上的预测技能。这不是外部标签，是"好奇心"这个驱动本身的定义。§9 辩论点 1。

## 4. v0 架构：六个器官

```
                ┌────────────── 并行关切（每拍各自演化）──────────────┐
                │  再激活(记忆脉冲)  惊讶(分区误差)  探究(学习进度)  忧惧(ΔC预测) │
                └──────────────────────┬───────────────────────────┘
                                       │ softmax 竞争 → 广播门控 g
外界 s(t) ──→ ┌────────────┐   m(再激活)   ┌──────────┐
身体 b(t) ──→ │  episodic   │────────────→ │  kernel   │──→ h(t) ──→ 策略/想象
             │  memory     │              │ h'=tanh(W·│        ┌→ 世界模型 ŝ(t+1)
             └────────────┘              │ h+W x+…)  │        └→ ΔC 预测器(忧惧)
                                         └──────────┘
   世界(物理) ←── 行动 a(t) ←── 内部模拟(用世界模型 rollout 打分，不训练)
```

| 器官 | v0 实现 | 它要回答的问题 |
|------|---------|--------------|
| 世界（虫世界） | 16×16 环面，两种物质只有效应无名分；能量/完整度；低能量→动作变弱，能量 0→**晕厥**（时间跳跃+记忆修剪+模型权重遗忘），完整度 0→麻痹 | 什么算"坏"由物理决定，由系统自己发现 |
| kernel | 32 维 tanh-RNN，**固定随机权重**（储层），每拍必跑，输入=感知+身体+再激活电流+广播门控 | 无输入时 h 是否保持结构化演化（S4） |
| episodic memory | (h_key, 经历, 结果) 存储；相似度检索→再激活电流注入 h；晕厥时随机修剪 20% | 记忆如何"浮上来"打断当下（走神现象学） |
| world model | 2 层 MLP：预测下一拍感觉+身体；按经验聚类分区记误差曲线 → 学习进度 LP=慢EMA−快EMA | 探究欲的燃料（Q2 的"学世界"） |
| 价值系统 | ΔC 预测器：哪些(h,身体,身体斜率)历史性地先于认知资本下跌 | 接近/回避如何从物理后果里长出来，无人教它怕死 |
| 竞争与认知策略 | 关切激活→softmax 竞争→广播；**回放分配 bandit**（特征=各分区的误差/LP/忧惧/新近度，REINFORCE，内部奖励=该分区误差下降） | Q2：复习策略是学出来的还是写死的（S1'、S3） |

**身体能力调制**（物理后果，非奖惩）：能量低→推力弱、感官噪声大；能量 0→晕厥（跳过 300 拍+记忆修剪 20%+权重向初始化遗忘 12%）——晕厥是对它**知识**的物理破坏，这是"自保可被无标签学出"的因果通路：饿死=烧掉自己的一部分认知资本。

## 5. 实验 E0：离线思考协议

```
W1(2500拍 醒·在线学习) → I(1500拍 冻结·内部工作) → W2(2500拍 醒·同世界) → W3(2000拍 醒·世界重掷)
```

- 无输入期 I：虫静止、世界静态→感官流熵≈0（Q1c 审计实测）。内部仍然：记忆脉冲、回放训练、bandit 学习。三种臂：
  - **满配臂**：LP 引导的回放分配 + 记忆脉冲 + bandit 更新
  - **均匀臂**：同等内部算力，但回放分区均匀随机（控制"挑对地方"之外的一切）
  - **对照臂**：只有 h 噪声漂移，无任何内部训练（控制"过了同样时间"之外的一切）
- 3 个随机种子 × 3 臂；指标逐拍记录：真实在线预测误差 EMA、C(t)、能量轨迹、晕厥/麻痹计数、趋利避害指数（用世界真值测量，仅供实验者看，不进大脑）。
- 判定：跑完按 §2 判据表自动输出 PASS/FAIL/INCONCLUSIVE。

**这一步是在证伪最小命题**：如果"重新消化已有经历"不能产生新的预测结构，那"无输入期认知有价值"这个前提本身要重造；如果连 E0 都过了，后面的问题（生成性想象、内核可塑性、学会分配计算）才值得逐层加码。

## 6. 谱系（各取一刀，不做复读机）

- **Dyna (Sutton 1990)**：从模型生成经验训练策略 → 我们取"离线重放有真增益"，但不取其奖励标签。
- **预测加工 / predictive coding**：误差即驱动；"预测-延期验证"想象 M1+ 再用。
- **Oudeyer IAC / Schmidhuber 创造性理论**：学习进度作为内在动机 → 探究欲的直接来源（源码级调查见 PRIOR_WORK.md）。
- **全局工作台（GWT, Bengio/Goyal）**：并行模块竞争有限广播 → 关切竞争机制的原型。
- **Dörner PSI 理论 / MicroPsi**：需求-情绪-调制参数的最小心智 → 我们取其"调制而非开关"的观点，v0 不做人格。
- **Beer 的 CTRNN 最小 agent**：体-脑耦合动力学传统，v0 的固定内核即其精神后代。

## 7. 里程碑

- **M0（本次）**：方案 + 可跑原型 + E0 对 S1–S4 初判。
- **M1**：行为涌现确认（趋利避害无标签稳定出现）；生成式想象入训练（带延期验证防自噬）；内核可塑性（h 本身开始被训练）。
- **M2**：认知策略升级（何时想象/何时回忆/信任谁，策略空间扩大）；世界非平稳化长期运行。
- **M3**：规模化（多虫/社会性扰动？）；探究欲的形态学分析（它"研究"世界的路径像不像科学家）。
- **M4**：LLM 作为外接语言器官：关切竞争触发语言模块（工具调用），语言产物作为广播事件回流——语言是器官，不是内核。

## 8. 风险与已知漏洞（自我曝光）

- C 用探针集度量"过去+近期"的预测技能，"学过去 vs 学未来"有张力，非平稳世界下需重审（M2）。
- 晕厥遗忘可能反过来被系统利用（故意晕厥"重置"以重获学习进度）——LP 定义为技能增量而非误差绝对值可部分免疫，需观察。
- 虫世界太简单→LP 饱和→探究欲测不出来；太难→学不到。E0 参数首跑后调。
- bandit 每期只有 ~30 次决策，统计功效低；S1' 阈值已放宽，不通过时先加块数再下结论。
- 固定内核的容量上限：若 h 表达不了任务需要的抽象，所有下游都会瓶颈——M1 的内核可塑性是解药。

## 9. 待辩论的设计决定（我单方面拍了，欢迎推翻）

1. **认知资本 C 作为唯一公理化目标 + 晕厥遗忘作为物理后果**：这是"自保无需生存本能"赌注的核心。反方观点：这是不是变相告诉它"知识=好"？我认为不算（好奇心公理，不是逐状态标签），但值得吵。
2. **想象数据不进训练（v0）**：保守换纯净。代价：无输入期的"新"只能来自重排旧信息，不能来自模型外推。M1 放开。
3. **内核不训练**：v0 可塑性全在读出网络。代价：h 的演化不是学出来的。M1 放开。
4. **探究欲操作化 = 分区级误差斜率**：够纯但粗糙（分区是在线 k-means）。更好：结构发现器（"这里存在我不知道的规律性"）→ M2。
5. **Q2 首次操作化 = 回放分配**：最小编但真实。若 S1'/S3 通过，M2 升级为"何时想象"的策略。
