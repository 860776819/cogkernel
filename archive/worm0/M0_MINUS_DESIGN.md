# M0-minus 实验设计：只做减法

> 2026-09-13。上一份文档：PRESET_AUDIT.md（承重偷渡 P1–P5）。Baseline A 已冻结于 tag `baseline-a`。

## 0. 靶心问题（唯一目标）

**在没有程序员指定"什么时候回忆、复习什么、什么值得关切"的情况下，内部动力学本身能否产生一次
非预定的、可溯源的、并会改变未来预测或行为的内部事件？**

三个必要条件（缺一不算）：
- **非预定**：事件时刻不来自任何 `% N` 定时器或实验者排的课表；
- **可溯源**：能指出它从哪来（哪段历史/哪个状态邻域），而非噪声尖峰；
- **有因果作用**：对它做干预（消融/扰动），未来预测或行为的轨迹与对照组分离。

地板定义（用户原话的制度化）：如果全部减到只剩**持续动力学 + 历史痕迹**，
所有"自发认知"消失——这个结果照单全收，它是"程序员替它想了多少"的定量答案。

测量纪律：**事件检测、干预、统计全部是实验者侧工具**（`tools/`），大脑内不新增任何机制。
所有对比均在 Baseline A 的世界与协议上进行（只换大脑变体），保证可比。

## 2. 内部事件探针（实验者侧工具，`tools/event_probe.py`）

M0M1 的分析工具，回答"非预定+可溯源+因果"三条件：

1. **检测（非预定）**：M0M1 变体跑**纯醒流**（6000 拍连续醒相，不含 idle——idle 脉冲本身是
   P5 定时事件，会污染"自发"检测），逐拍记录 `maxcos_t = max_key cos(h_t, key)`。
   事件 = maxcos 自下而上穿过 0.90 且距上次事件 ≥50 拍（此窗口是**测量窗**，大脑不知情）。
2. **溯源（非随机）**：两层检查——(a) 事件率 vs 旋转零假设：把 h 旋转后过同一检测器，
   事件率应显著更高（排除"32 维 tanh 流形本来路过键邻域"的平凡解释）；
   (b) 情境锁定：事件时刻的当下感觉 vs 被路过记忆的感觉段距离，应小于随机时刻的距离
   （"想起"是否由当下情境勾起，还是纯漂移）。
3. **因果（要害点）**：孪生干预。检测到事件时，深拷贝整个 agent，对孪生体施加单次状态踢
   （h += 0.3×单位随机向量），主体与孪生体各继续 300 拍，度量行动流分歧与误差分歧。
   对照：同样幅度/数量的踢施加在**随机非事件时刻**。若事件时刻的干预造成的未来分歧显著大于
   随机时刻 → 这些内部状态是动力学的分岔要害（因果特权）；若无差异 → "内部事件"只是风景，不是引擎。

## 3. 预注册的结果解读表（先写答案格式，再跑）

| 结果 | 解读 |
|------|------|
| M0M1 事件率≈旋转零假设 | 自发路过不存在，h 的"接近记忆"全是平凡几何 → P3 的课表此前是唯一回忆来源（承重实锤） |
| M0M1 事件存在+情境锁定+因果特权 | 首个合格的"非预定内部事件"，进入下一阶段研究其来源结构 |
| M0M1 事件存在但无因果特权 | 风景式的联想流：可见但不改变去向——同样重要，"想"还需要别的引擎 |
| M0M2 行为≈Baseline A | 安装的目标函数无必要，动力学自带觅食结构（爆炸性结果，存疑优先查实现） |
| M0M2 行为崩坏 | M0 的"虫想吃饭"主体是程序员的目标函数在想吃（预期结果，量化 P2 偷渡量） |
| M0M3 仍有回避 | 物理弱通路（噪声→预测变差）足够承载生存涌现 → 可以删掉 P1 这根人工桥 |
| M0M3 回避消失 | P1 承重实锤：M0 的"怕死"是兑换率制造出来的；无标签生存涌现需要重新设计（或不可能） |

无论哪种结果都保留并写入 FINDINGS，不为 PASS 修系统。
