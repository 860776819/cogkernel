# Soul-0 研究文档（按研究顺序阅读）

本目录按时间顺序收录 Soul-0 的全部研究文档。每项一句话说明：

## 1. Foundation（共识与术语）
- [SOUL0_FOUNDATION.md](SOUL0_FOUNDATION.md)
  ——项目定位：研究对象"原体（Proto）"，核心术语"存在域/存在边界"的定义，研究纪律与拒绝偷渡清单。

## 2. Survey（第一轮调查）
- [SOUL0_EXISTENCE_SURVEY.md](SOUL0_EXISTENCE_SURVEY.md)
  ——调查"存在=满足条件，还是靠自身活动维持"，提炼七种机制原型，比较 A/B 两个极端。
- [SOUL0_NORMATIVITY_SURVEY.md](SOUL0_NORMATIVITY_SURVEY.md)
  ——调查"存在事实如何可能变成对原体自身重要的事"，定义 A/B/C 三层判据与资格线。

## 3. E0（第一个实验：最小存在组织）
- [SOUL0_E0_DESIGN.md](SOUL0_E0_DESIGN.md)
  ——Proto-0 的设计与实现：两个组分互相维持的组织，验证存在域、恢复、不可逆消散与切断对照。

## 4. E0.5（内部差异审计）
- [SOUL0_E0_5_DISCRIMINATION.md](SOUL0_E0_5_DISCRIMINATION.md)
  ——审计 Proto-0 是否已有"同等扰动、不同内部响应"：确认组织结构产生的暂态差分响应。

## 5. E1（调节自由度）
- [SOUL0_E1_REGULATION_DESIGN.md](SOUL0_E1_REGULATION_DESIGN.md)
  ——设计一个由组织产生、有自己动态、能反向调制自维持过程的内部自由度（R1 方案）。
- [SOUL0_E1_FINDINGS.md](SOUL0_E1_FINDINGS.md)
  ——R1 的实现与验证结果：五个判据全部通过，含 ±ε 对照与命运分岔。

## 6. Atlas-0（状态空间图谱）
- [SOUL0_ATLAS0_DESIGN.md](SOUL0_ATLAS0_DESIGN.md)
  ——对 R1 系统状态空间做双图谱测绘的设计（Formal 数学合法 / Reachable 历史可达）。
