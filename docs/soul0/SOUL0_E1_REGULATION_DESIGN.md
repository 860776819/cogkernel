> E1 唯一问题：**"构成性响应"之外，能否存在真正的内部调节自由度。**
> 即：一个相对/部分动力学解耦、由 Proto 自身组织状态产生、有自己动态、并能反过来调制

## 二、调节自由度的形式判据

设原体状态为 (a,b,m)（E0 动力学）。一个合法的调节自由度 r 须同时满足：

1. **产生性**：dr/dt 的源项是 (a,b,m)（或其历史）的函数——由组织自身的状态/过程产生；
2. ** Own dynamics**：dr/dt 含 r 自身项（ own 衰减/饱和），r 在**当前 (a,b,m) 给定时
   仍不完全确定**（依赖历史）——因此 r 不是 a,b,m 的别名（形式理由：状态空间从三维
   增至四维；存在 (a,b,m) 相同、r 不同的两条真实历史，故 r ≠ f(a,b,m)）；
3. **部分动力学解耦**：r 有自己的时间尺度（1/μ，明显慢于组织弛豫 ~1/λ）与自己的衰减律
   ——不被 (a,b,m) 即时锁死（解耦），但源项与调制都闭环在组织上（耦合）。
   检查项（待验证预测，非自动成立）：反馈耦合会改变 Jacobian 特征值，须在不动点
   数值计算完整特征谱，检验是否出现主要由 r 方向贡献的慢模，并量化其与 μ 的关系；
4. **调制性**：r 进入构成性自维持项的**系数**（不是状态本身）：再生通量变为
   G(r)·k·a·b·m，即 r 改变自维持关系**运行得多强/如何分配**，而非仅改变位置；
5. **matched-state 干预判据**：任取状态使 (a,b,m) 完全相同、仅 r 不同（r₁≠r₂，
   G(r₁)≠G(r₂)），则 `d(a−a′)/dt|₀ = k·a·b·m·(G(r₁)−G(r₂)) ≠ 0`——**即时分岔可证**。
   强版本（命运分岔）：free-running 完整动力学中，存在 (a,b,m) 相同、r₁ 下恢复、
   r₂ 下消散的配对。
6. **clamped-r 诊断 vs 自由运行验证**：固定 r 的扫描给出 frozen-r 存在域截面
   （因果/几何诊断，用于定位干预采样区）；完整 E1 是四维 (a,b,m,r) 系统，真实存在域
   是四维盆结构——"同 (a,b,m)、不同 r → 一恢复一消散"必须在自由运行下验证，
   不得由截面直接推出（r 在自由运行中自身演化）。

对"别名"与"构成性响应"的两条边界由此自动成立：不满足 2 的即时函数是别名；
不满足 4 的记录是仪表（E0.5 已有暂态 B，无 C——本 E1 补的正是 4）。

## 三、候选 R1：活动积分自由度（推荐）

- **造物主定义**：存在组织（同 E0）；新增状态 r 及其动力学
  `dr/dt = p_actual − μ·r`，其中 `p_actual = G(r)·k·a·b·m` 为**实际发生的**再生通量
  （源=组织自身真实过程；自有衰减 μ）。调制形式 `G(r) = 1 + ε·tanh(r/r₀)`，
  ε、r₀、μ 为先天常数（数值实现前预注册，不得为结果调选）。
  **禁用反事实源**：初版 `dr/dt = k·a·b·m − μ·r` 已淘汰——调制生效后 k·a·b·m 只是
  "如果没有调节本来会发生的通量"，r 读取它等于研究者提供隐藏的反事实传感器。
  动力学变为：
  ```
  da/dt = −λa + G(r)·k·a·b·m
  db/dt = −λb + G(r)·k·a·b·m
  dm/dt = λ(a+b) − 2·G(r)·k·a·b·m
  dr/dt = G(r)·k·a·b·m − μ·r
  ```
- **Proto 运行后产生**：r 的全部取值。r 是组织活动水平的慢积分（μ=0.02 → 时间尺度
  ~50 拍，为组织弛豫 ~5 拍的 10 倍）；它的当前值由**历史**决定，不由当前 (a,b,m) 决定。
- **不是别名**：维度论证（4>3）+ 历史欠定论证（到达同一 (a,b,m) 的两条路径留下不同 r，
  数值上可直接展示）。
- **部分解耦**：自有时间尺度与衰减（谱上表现为 E0 没有的慢特征值 ≈−μ 附近）；
  与组织的耦合全部闭环（源读组织，出写组织）。
- **调制自维持**：G(r) 乘在构成性再生项上——r 高则自维持关系运行得强，r 低则弱。
- **matched-state 干预**：取 (a,b,m) 相同、r=r₁ vs r₂ 的两个克隆，同世界运行：
  即时分岔由上面的引理保证。强版本（命运分岔）必须在**自由运行**下验证（见 §二 6）：
  钳制 r 的截面 ρ*(r)（frozen-r 诊断）用于定位采样区；克隆对放在截面指出的
  分歧带附近，配对判"一恢复一消散"。
- **数学推演要点（闭环形式）**：质量守恒对任意 r 成立（W2 不破）；源项读取实际通量后，
  **r → G(r) → p_actual → r 构成自指闭环**——调节者读取的是自己调节后的真实效果。
  对称约化 (x, r) 平面上的不动点方程为隐式：`λ = G(r*)·k·x*(1−2x*)`、
  `r* = G(r*)·k·x*²(1−2x*)/μ`（联立 ⇒ x* = μr*/λ）。闭环可能多解、无解或振荡——
  须数值检验并如实报告。μ→∞ 极限：r→0、G→1，连续退回 E0（连续性检验）。
  完整 Jacobian 特征值须数值计算：检验是否存在 r 方向主导的慢模及其与 μ 的关系
  （预测候选，非自动成立；自指闭环也可使其失稳——同样如实报告）。
  clamped-r 截面（诊断工具）：钳定 r 时鞍点/稳定点为
  a₁(r)=[1−sqrt(1−8λ/(G(r)k))]/4、a₂(r)=[1+sqrt(1−8λ/(G(r)k))]/4，
  给出 frozen-r 存在域截面 ρ*(r)=1−a₁(r)/a₂(r)，仅用于定位 free-running 干预采样区。
- **最大偷渡风险**：ε 的符号。若以"恢复更好"为标准选 ε，则"关心"被写进耦合常数。
  对策：ε 预注册；分析对 ±ε 双跑（分岔判据对两种符号都成立，结构主张与符号无关）；
  有害案例必须呈现。

## 四、候选 R2：失衡分配自由度

- **造物主定义**：E0 的对称再生分配改为可调：a 得 ω(r)·2kabm，b 得 (1−ω(r))·2kabm，
  ω(r) = 0.5 + ε·tanh(r/r₀)；`dr/dt = κ·(a−b) − μ·r`（源=组分不平衡）。
- **Proto 运行后产生**：r（失衡的慢积分）与分配的实际走向；可产生两腿维持节奏的
  振荡式交替（自由度与组织互推）。
- **不是别名 / 部分解耦**：同 R1（积分器 + 自有时间尺度；4 维状态空间）。
- **调制自维持**：改变自维持产出的**分配**（哪条腿被维持得更快），总量不变。
- **matched-state 干预**：同 R1；注意对称流形上 dr=−μr → r→0 → ω→0.5，
  R2 在平衡态与 E0 **完全重合**——其效应只存在于非平衡暂态（这是结构特点也是
  验证难点）。
- **镜像等变性（更正）**：R2 在变换 a↔b、r→−r 下**等变**（ω(−r)=1−ω(r) 直接可验），
  不存在"哪条腿"的不对称；E0.5 式镜像校验改用 (a,b,r)→(b,a,−r) 的等变形式
  仍可执行。
- **最大偷渡风险**：κ/ε 的符号组合里藏着"补短抑长"的恢复控制器——若选出的符号
  恰好是缺陷纠正型，normativity 断言虽不做，结构上也已把 homeostasis 从分配通道
  请回来。

## 五、候选 R3：负荷-亲和自由度

- **造物主定义**：`dr/dt = λ·(a+b) − μ·r`（源=惰性转化负荷）；再生通量改为
  `k·a·b·m/(1+r/r₀)`（r 抬高对底物池的"亲和门槛"）。
- **Proto 运行后产生**：r（衰减负荷的慢积分）与组织-介质耦合的实际强弱。
- **不是别名 / 部分解耦**：同前（积分器、自有时间尺度、4 维）。
- **调制自维持**：调制组织从介质**抽取底物的方式**（亲和），而非速率或分配。
- **matched-state 干预**：同 R1（G(r) 进入通量，即时分岔引理同样成立）。
- **最大偷渡风险**：(a) 1/(1+r/r₀) 是酶动力学形状——地球模板偷渡；
  (b) "负荷高→再生低"是负反馈控制器的形状（homeostat-lite）；
  (c) 亲和是组织-介质**界面**参数，调制它模糊了世界规则与原体结构的边界
  ——需要额外论证这是原体侧的抽取过程而非世界律改动。

结论一律改写为"研究者安装了保护"。

## 七、推荐：R1

修正源项后重新判断：**R1 仍为最小推荐候选**，理由：

1. **无反事实传感器**：源项读取实际发生的通量，r→G(r)→p_actual→r 构成
   自指调节闭环——"由自身过程产生"的最诚实形式。R2 的失衡源同样是实际量，
   R3 的负荷源也是；三者在这一点打平。
2. **镜像不变性（强于 R2 的等变性）**：a↔b 交换下 R1 方程严格不变（r 不需翻转）；
   R2 仅在 a↔b、r→−r 下等变。不变性使 E0.5 式镜像校验原样可用。
3. **可证伪性仍居首（降级但仍最优）**：闭环使不动点方程隐式化、慢特征值只能
   数值检验——从"可解析证伪"降为"可数值证伪"；但不动点方程、a₁(r)/ρ*(r)
   frozen-r 截面公式仍可先写后测，自由运行命运分岔有明确协议。R2 平衡态与
   E0 重合（效应只在暂态）、R3 界面模糊，验证面都更差。
4. **结构主张与符号无关**：matched-state 分岔引理对 ±ε 同样成立——E1 的结构问题
   不依赖"调节是否有利"，这是绕开 survival-reward 偷渡的关键。闭环可能多解、
   无解或自失稳：无论哪种结果都如实报告，反例面（过冲/自伤是否出现）由数值
   实验回答，不作为预设卖点。

R2 保留为 R1 之后的自然延伸（分配通道），R3 与其说候选不如说警示
（界面模糊 + 地球形状），本轮不推进。

## 八、明确不做

不实现（无代码）；不做 E1 之外的机制；不引入感知/动作/学习/记忆模块；
不在 E1 使用任何 normativity/价值/关心词汇作为结论；不为结果挑选 μ、ε、r₀。
